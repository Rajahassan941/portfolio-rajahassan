# Mahamood Rajahassan — Portfolio

A premium dark developer portfolio built with **Next.js 16 (App Router, Cache Components)**, **TypeScript**, **Tailwind CSS v4**, **Motion**, **GSAP**, **Lenis**, **React Three Fiber** and shadcn-style UI primitives.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build (the page is fully static)
npm run lint && npm run typecheck
```

## ✏️ Updating content — no UI changes needed

All content lives in `src/data/`:

| File | What it controls |
| --- | --- |
| `profile.ts` | Name, headline, intro, rotating roles, email, socials, resume path, availability badge, nav |
| `experience.ts` | Career timeline (dates, roles, responsibilities, focus tags) |
| `projects.ts` | Featured projects: overview, contribution, challenges, tech, screenshots, links |
| `skills.ts` | Skill categories and honest proficiency levels (`primary` / `hands-on` / `exposure`) |
| `content.ts` | About copy, strengths, stats, differentiators, journey, contact copy |

### Placeholders to replace before launch

Anything containing `YOUR-`, `example.com` or `[brackets]` is a placeholder and is **visibly flagged on the site** (dashed amber badges) until you replace it.

- [ ] `profile.ts` — email, LinkedIn URL, GitHub URL
- [ ] `experience.ts` — start/end dates (`[Start date]`, `[End date]`)
- [ ] `public/resume/Mahamood-Rajahassan-Resume.pdf` — currently a one-page placeholder PDF
- [ ] `projects.ts` — screenshots (`image`), live/GitHub links, and review the drafted *contribution* / *challenges* text
- [ ] `content.ts` — `yearsOfExperience` (stat stays hidden while `null`)
- [ ] `skills.ts` — adjust proficiency levels so they match reality
- [ ] `NEXT_PUBLIC_SITE_URL` in your hosting environment

**Stats are derived from the data** (companies = number of experiences, technologies = number of skills, etc.), so they're always truthful.

**Screenshots:** put images in `public/projects/` and set `image: { src: "/projects/x.png", alt: "…" }`. Until then, an abstract illustrated preview is shown with a "Screenshot placeholder" tag.

## 📬 Contact form

The form validates on the client and the server (shared Zod schema in `src/lib/contact-schema.ts`) and submits to a Server Action (`src/app/actions/contact.ts`) with a honeypot field for spam.

- **With [Resend](https://resend.com) configured** (see `.env.example`), messages are emailed to you.
- **Without it**, the form still validates, then opens the visitor's email app with the message prefilled.

```bash
cp .env.example .env.local
```

## 🧱 Structure

```
src/
  app/            layout, page, SEO routes (sitemap, robots, OG image), server action
  sections/       Hero, About, Skills, Experience, Projects, Differentiators, Journey, Contact
  components/
    layout/       Navbar, Footer, loader, smooth scroll, custom cursor, scroll progress
    hero/         animated workspace, role rotator, lazy-loaded 3D scene
    projects/     project card + illustrated previews
    contact/      contact form
    ui/           Button, fields, Reveal, Magnetic, SpotlightCard, counters…
    icons/        brand/tech icons (simple-icons subset, regenerated by `npm run icons`)
  data/           ← all editable content
  constants/      site config, tech registry
  hooks/ lib/ types/
```

Adding a new technology: add its slug to `scripts/generate-icons.mjs` (if it has a simple-icons logo), run `npm run icons`, then register it in `src/constants/tech.ts`.

## ⚡ Performance & accessibility

- The page is statically prerendered. The WebGL scene loads only on desktop, after the browser is idle, and pauses when it's off-screen.
- `prefers-reduced-motion` turns off smooth scrolling, the loader, the cursor, parallax, the 3D scene and looping animations.
- The custom cursor and magnetic effects only run with a fine pointer (mouse or trackpad). The native cursor always stays visible.
- The site has semantic landmarks, a skip link, ARIA tabs, a labelled form with live error messages, and visible focus rings.
